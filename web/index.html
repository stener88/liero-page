▸ QUESTIONS

FAQ

Does it change the website?

No. Liero.page takes a snapshot of what's on your screen and plays on that. Leave the game and the page is exactly as it was.

What do my friends see?

The snapshot of your screen, like sharing a screenshot. Pick a page you're happy to show, not your inbox.

Does it work on every site?

Almost. Chrome doesn't let extensions run on its own pages (settings, the Web Store) or some PDFs.

Do my friends need to install anything?

No. Invite links open the game in any desktop browser. Only the host needs the Chrome extension.

Can I play on my phone?

Not yet. You need a keyboard and mouse.

Is it free?

Yes.
