LIERO.PAGE

Privacy policy

Last updated: October 2026

The short version

Liero.page doesn't have accounts, doesn't track you, and doesn't sell anything. It only captures a page when you start a game, and only so the people in your match can play on it.

What the extension does

  • Only when you start a game (by clicking the Liero.page icon), the extension takes a screenshot of the visible part of the current tab. It also reads the page's layout to work out which areas are solid.
  • That screenshot and layout map are sent to the Liero.page game server so the other players in your match can see the same map.
  • The extension stores your player name and settings (sound on/off, server address) in your browser's extension storage.
  • The extension has no access to any page until you click the Liero.page icon (or press Alt+Shift+P) on it. It doesn't read your browsing, and it does nothing in the background.

What the game server keeps

  • While a match is running, the server holds the map, the craters, player names and positions in memory.
  • When everyone has left the match, the room is reset and the map is discarded. Maps are not written to a database.
  • Like any website, our hosting provider (Cloudflare) processes IP addresses to deliver traffic.

What other players see

Everyone in your match sees the screenshot of the page you started the game on. Treat it like sharing a screenshot: avoid starting games on pages with private information.
